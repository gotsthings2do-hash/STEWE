# Stewart Enterprise Token (STEWE)

STEWE is a fixed-supply ERC-20 community token associated with Stewart's Enterprise LLC. It is deployed on **Base Mainnet**. Current utility is under development: possible future uses include customer rewards, promotions, collectibles, and community benefits. These uses are proposals, **not existing functionality or guaranteed benefits**.
